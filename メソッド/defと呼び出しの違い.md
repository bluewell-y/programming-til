# defと呼び出しの違い

前提：[メソッドとは何か.md](./メソッドとは何か.md)

## 学んだこと

`def〜end` は処理を「登録」するだけで、この時点ではまだ実行されない。実際に実行されるのは、メソッド名だけを書いて「呼び出した」タイミング。

```ruby
def greet
  puts "こんにちは"
end

greet
greet
greet
```

- `def greet ... end` の部分は1回しか書かれていないが、実行はされていない（レシピを書いただけの状態）
- `greet` と書いた行が「そのレシピを使って実際に処理を行う指示」
- `greet` を3回書いたので、レシピの中身（`puts "こんにちは"`）が3回実行され、「こんにちは」が3回表示される

## ハマりポイント

最初、`def greet ... end` の中身（`puts "こんにちは"`）が1回しか書かれていないのに、なぜ複数回「こんにちは」と表示されるのかが分からなかった。

- 勘違いしていた点：`def〜end` の中身がそのままコピーされて複数回書かれている、と思い込んでいた
- 実際：`def〜end` は「登録」のみ。`greet` という呼び出しの行を書いた回数分だけ、登録済みの処理が実行される
- 次回同じ疑問が出たら確認すること：「これは登録の部分か、呼び出しの部分か」をまず区別する

## 重要なポイント

- `def 名前 ... end` → 登録（この時点では実行されない）
- `名前` とだけ書く → 呼び出し（ここで実行される）
- 呼び出しを書いた回数だけ、中身が繰り返し実行される
