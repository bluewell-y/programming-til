# デフォルト値（デフォルト引数）

前提：[引数.md](./引数.md)

## 学んだこと

引数を渡さなかった場合に備えて、あらかじめ既定の値（デフォルト値）を設定できる仕組み。`def メソッド名(引数名 = 既定値)` という書き方をする。

## コード

```ruby
def greet(name = "名無しさん")
  puts "#{name}さん、こんにちは"
end

greet("田中")  # => 田中さん、こんにちは
greet          # => 名無しさんさん、こんにちは
```

- `greet("田中")` → 情報が渡されたので、`name` には `"田中"` が入る
- `greet`（引数なし） → 何も渡されなかったので、デフォルト値の `"名無しさん"` が使われる

## ハマりポイント

デフォルト値に `"名無しさん"` を設定し、表示側の文字列テンプレート（`"#{name}さん、こんにちは"`）にも `"さん"` を含めていたため、実行結果が「**名無しさんさん**、こんにちは」と「さん」が重複してしまった。

- 原因：デフォルト値の文字列と、表示テンプレートの文字列の両方に同じ語尾（「さん」）を入れてしまっていた
- 次回同じことが起きないための確認ポイント：デフォルト値を設定するときは、実際に表示される文章全体を組み立てた状態で一度確認する

## 重要なポイント

- デフォルト値を設定すると、引数を省略してもエラーにならず呼び出せる。
- デフォルト値と、それを埋め込む文字列テンプレートの組み合わせによって、意図しない表示崩れが起きることがあるので注意する。
