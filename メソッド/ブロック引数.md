# ブロック引数（yield）

前提：[可変長引数.md](./可変長引数.md)（`each`の使い方を先に確認しておくと理解しやすい）

## 学んだこと

`do...end`で書く処理のかたまりを「ブロック」と呼ぶ。メソッドの中で`yield`という命令を使うと、「メソッドを呼び出すときに渡されたブロックの中身を、その場所で実行する」ことができる。以前使っていた`each`も、内部でこの仕組み（`yield`）を使って、渡された`do...end`の処理を繰り返し実行している。

## コード

### 基本の書き方

```ruby
def greet
  puts "こんにちは、始まります"
  yield
  puts "こんにちは、終わりました"
end

greet do
  puts "ブロックの中身が実行されました"
end
```

実行結果（上から順番通りに実行される）：
こんにちは、始まります
ブロックの中身が実行されました
こんにちは、終わりました


- `greet do ... end` → `greet`を呼び出すときに、`do...end`の中身（ブロック）を渡している
- `yield` → 渡されたブロックの中身を、**書かれたその場所で**実行する命令

### yieldが複数回ある場合

```ruby
def greet
  yield
  puts "こんにちは、始まります"
  yield
end

greet do
  puts "ブロックの中身です"
end
```

実行結果：
ブロックの中身です
こんにちは、始まります
ブロックの中身です


- `yield`が書かれた回数だけ、その都度ブロックの中身が実行される
- `yield`は「メソッドの最後にまとめて実行される」のではなく、書かれた場所・タイミングでその都度実行される

## ハマりポイント

- 最初、`yield`が「メソッドの最後にまとめて実行される」ものだと勘違いしていた。
  - 勘違いしていた点：`yield`をどこに書いても、ブロックの中身は最後にまとめて実行されると思っていた
  - 実際：`yield`は書かれたその場所で、その瞬間に実行される。複数回書けば、その都度実行される
  - 次回同じ疑問が出たら確認すること：「これは実行されるタイミングがいつなのか」を、コードを上から順に1行ずつ追って確認する

## 重要なポイント

- `do...end`で渡す処理のかたまりを「ブロック」と呼ぶ。
- `yield`は「渡されたブロックの中身を、その場所で実行しろ」という命令。
- `yield`は書かれた場所・回数だけ、その都度実行される（まとめて最後に実行されるわけではない）。
- `each`のような繰り返し処理も、内部では`yield`の仕組みを使って動いている。
