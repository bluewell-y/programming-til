# メソッドとは何か

## 学んだこと

メソッド（method）とは、「ひとまとまりの処理に名前をつけたもの」。同じ処理を何度も書かずに済むように、`def 名前 ... end` で処理を登録しておき、`名前` と書くだけで呼び出せるようにする仕組み。

## コード

```ruby
def greet
  puts "こんにちは"
end

greet  # => こんにちは
```

- `def greet ... end` → `greet` という名前の処理を「登録」する
- `greet` とだけ書く → 登録した処理を「呼び出す」→ 実際に実行される

## 重要なポイント

- メソッドの目的は「同じ処理を何度も書かなくて済むようにすること」。
- `def〜end` の中身は、名前を呼び出した回数だけ実行される。
