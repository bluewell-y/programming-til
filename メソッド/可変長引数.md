# 可変長引数

前提：[引数.md](./引数.md)

## 学んだこと

`*`（アスタリスク）を引数名の前につけると、呼び出し時に渡された値がいくつであっても、まとめて1つの配列として受け取れる。これを可変長引数と呼ぶ。値の数が変わっても、同じメソッドで対応できるのが利点。

## コード

```ruby
def greet(*names)
  puts names
end

greet("田中", "鈴木", "佐藤")
```

- `*names` → 渡された値をすべて1つの配列にまとめて `names` に入れる
- 上記の場合、`names` の中身は `["田中", "鈴木", "佐藤"]` という配列になる
- 渡す人数が1人でも3人でも、`names` は常に配列という「形」になる（中身が1個でも `["田中"]` のように配列）

## each（配列の中身を1つずつ取り出す）との組み合わせ

```ruby
def greet(*names)
  names.each do |name|
    puts "#{name}さん、こんにちは"
  end
end

greet("田中", "鈴木")
# => 田中さん、こんにちは
# => 鈴木さん、こんにちは
```

- `names.each do |name| ... end` → `names`（配列）の中身を1つずつ取り出し、`name`という箱に入れて、`do`から`end`までの処理を繰り返す
- 複数形の `names`（配列全体）から、単数形の `name`（1つずつの値）を取り出す、という命名の対応関係がある

## ハマりポイント・疑問点

- `*names` の中身を「文字列がそのまま入る」とイメージしてしまい、実際には「配列（複数の値をまとめた入れ物）」になっている点でつまずいた。
  - 勘違いしていた点：`greet("田中", "鈴木")` の `names` が `"田中、鈴木"` のような1つの文字列になると思っていた
  - 実際：`names` は `["田中", "鈴木"]` という配列になり、`puts names` で表示すると1つずつ改行されて表示される
  - 次回同じ疑問が出たら確認すること：「これは1つの値か、複数の値をまとめた配列か」をまず区別する
- 通常の引数（`name`、`*`なし）と、可変長引数（`names`、`*`あり）の名前が似ていて混同しやすかった。呼んでいるコードのどの引数の話をしているか、都度定義部分（`def`の行）に立ち返って確認するとよい。

## 重要なポイント

- `*引数名` は「渡された値をすべて配列としてまとめて受け取る」書き方。
- 可変長引数を使うと、渡す値の数が変わっても同じメソッドで対応できる。
- `配列名.each do |要素名| ... end` で、配列の中身を1つずつ取り出して同じ処理を繰り返せる。
