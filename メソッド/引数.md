# 引数（argument）

前提：[メソッドとは何か.md](./メソッドとは何か.md)、[defと呼び出しの違い.md](./defと呼び出しの違い.md)

## 学んだこと

引数とは、メソッドを呼び出すときに「情報を渡す」ための仕組み。`def greet(name)` のようにカッコをつけると、呼び出し時に渡した情報が `name` という箱に入り、メソッドの中でその値を使えるようになる。

## コード

```ruby
def greet(name)
  puts "#{name}さん、こんにちは"
end

greet("田中")  # => 田中さん、こんにちは
greet("鈴木")  # => 鈴木さん、こんにちは
```

- `#{}` は文字列の中に変数の中身を埋め込む書き方（式展開）
- `name` は呼び出すたびに中身が変わる「空っぽの箱」のようなもの

複数の引数を受け取ることもでき、渡す順番と受け取る順番が対応する。

```ruby
def greet(name, time)
  puts "#{name}さん、#{time}"
end

greet("田中", "おはようございます")  # => 田中さん、おはようございます
```

## 発生した問題・エラー（概念として確認したもの）

`def greet(name)` は「呼び出すときは必ず1つ情報を渡す」という約束になる。この約束と異なる数の値を渡すとエラーになる。

- 原因：引数の数（渡す数）と、`def` で定義した引数の数（受け取る数）が一致していない
- 想定されるエラーメッセージ：`wrong number of arguments (given 2, expected 1)`（「渡された引数は2個ですが、期待していたのは1個です」という意味）
- 対処：`def` で定義した引数の数と、呼び出し時に渡す値の数を必ず一致させる

## 重要なポイント

- 引数を使うことで、同じメソッドでも呼び出すたびに異なる値を処理できる。
- 引数の数は「約束」であり、呼び出し時に渡す数と一致していないとエラーになる。
