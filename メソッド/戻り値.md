# 戻り値（return value）

前提：[引数.md](./引数.md)

## 学んだこと

メソッドの中で `puts` を使わずに、最後に評価された値（式）を書くと、その値が自動的に呼び出し元に「返る」。これを戻り値と呼ぶ。Rubyでは `return` という単語を省略して書くのが一般的。

## コード

```ruby
def add(a, b)
  a + b   # ここで計算はされるが、表示はされない
end

result = add(4, 6)  # add(4, 6) が実行され 10 という値になり、result に代入される
puts result          # ここで初めて画面に表示される => 10
```

## 疑問点と解決（Q&A形式）

**疑問：`puts` がないのに、なぜ `a + b` が実行されたのか？**

- 「実行（評価）される」ことと「画面に表示される」ことは別のこと。
- `a + b` は `puts` の有無に関わらず必ず計算される。ただし `puts` がなければ、その結果は画面に表示されない。
- メソッドの中で最後に評価された値（ここでは `a + b` の結果）は、自動的に「戻り値」として呼び出し元に返される。これはRubyの仕様（`return` を省略できる）。
- `result = add(4, 6)` のとき、内部では次の順番で処理されている。
  1. `add(4, 6)` が呼ばれる
  2. `a + b` が計算され `10` になる（この時点では表示されない）
  3. `10` が戻り値として返される
  4. `result = 10` という代入が行われる
  5. `puts result` で初めて画面に `10` が表示される

## ハマりポイント

- 「計算（評価）される」ことと「表示される」ことを同じものだと思い込んでいた。`puts` は「表示しろ」という別の命令であり、計算そのものをしているわけではない、という区別が最初はついていなかった。
- 次回同じ疑問が出たら確認すること：「この行は計算（評価）の話か、表示の話か」をまず切り分ける。

## 重要なポイント

- `puts` ＝「表示しろ」という命令。`return`（省略可）＝「呼び出し元に値を返せ」という命令。この2つは別物。
- メソッドの中で最後に評価された値が、自動的に戻り値になる。
